# Реальные истории

Уличный листок для стола. Карточная игра на одном телефоне: тема, как её рассказывать, и ор редакции. Истории игроков — интервью газете. Титул истории достаётся тому, кого признал стол. Пересдача клеит трусливый титул тому, кто сдрейфил.

Играет от двух до шести. Сдач столько, сколько людей за столом. «Завершение игры» обрывает партию и показывает сводку.
